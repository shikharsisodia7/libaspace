# One manual item before submission

1. Take an authentic screenshot of your LinkedIn profile that visibly shows your connection count (the assignment specifies 300+ connections for the LinkedIn option).
2. Save it as `public/submission-assets/linkedin-connections.png`.
3. Run `npm run dev` and open the LinkedIn section to confirm the image appears correctly.
4. Commit and push that single asset before submitting.

The website automatically renders this exact filename when it exists. No fabricated substitute is included.
